# 🏎️ Drift Circuit 3D

A one-finger 3D arcade drift-racing game that runs entirely in the browser — no install, no build step. Just open it.

**Play:** open the GitHub Pages link for this repo on any phone or desktop.

## Controls
- **Touch:** hold anywhere = accelerate · drag left/right = steer · drag down = brake/reverse · hold the **NITRO** button = boost
- **Desktop:** **W/A/S/D** to drive · **Space** = handbrake · **Shift** = nitro
- Hard corner at speed and the tail breaks loose — chain drifts for points.

## Features
- Randomly generated hilly circuit every load (⟲ New Track)
- Realistic 5-speed gearbox + reverse, grounded suspension wheels, drift physics
- Nitro boost, synthesized engine/tyre/shift audio
- 3-2-1 countdown, best-lap **ghost car**, minimap
- Day/night cycle with headlights, and toggleable rain (wet grip)

## Tech
Single `index.html` + a local copy of [Three.js](https://threejs.org) (`three.min.js`). Pure static site — hostable anywhere.
